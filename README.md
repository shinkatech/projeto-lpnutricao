# Clara Mendes — Leitura metabólica

Landing page de nutrição metabólica de precisão. Visual editorial (tinta, cobre, osso), não clínica genérica.

## Identidade

- **Profissional:** Dra. Clara Mendes, CRN-3 18472
- **Especialidade:** nutrição metabólica de precisão
- **Público:** mulheres 32–48 que já tentaram dieta demais
- **Oferta:** Protocolo Sinal, 12 semanas
- **Contato:** a visitante escreve para a Clara (WhatsApp, e-mail ou estúdio). Troque número e e-mail em `src/lib/contact.js`.

## Stack

React 19 · Vite · Tailwind CSS v4 · Framer Motion

## Como rodar

```bash
npm install
npm run dev
```

Build de produção:

```bash
npm run build
npm run preview
```
